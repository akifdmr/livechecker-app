# S2 — RBAC, ownership scope, and credits

Reuse `api/auth.js` JWT and RBAC. Export `requireAuth`, `requireAdmin`,
`scopeByOwner`, and `assertCanView` helpers without changing token semantics.
Enforce owner scope on user ledger and payment records; admin access is explicit.

Implement atomic `CreditsSettingsService.spend/grant/getBalance`, using a user
row lock and idempotency key. Reject overspend. Settings writes are admin-only,
audited, and restricted to non-secret allowlisted values. Fees are configurable
only for passive BIN metadata and explicit capture operations. Do not apply a
live-check/auth fee or add payment automation.

Completion format: DONE, paths, reused code, commands and whether executed,
remaining risks.

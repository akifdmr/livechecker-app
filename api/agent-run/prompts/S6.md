# S6 — Admin and ledger APIs

Reuse existing admin auth, RBAC, and audit. Add admin-only settings/provider
default/credit grants and global views of token enrollment metadata, provisions,
and transaction metadata. Never return provider tokens or raw provider payloads.
Add a user-scoped ledger endpoint; a non-admin must receive 403 on settings,
provider configuration, and credit grants. Audit all writes.

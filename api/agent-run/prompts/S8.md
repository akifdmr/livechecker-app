# S8 — Safe certification

Run repository-local tests and the web build. Use synthetic inputs only. Do not
run database migrations or payment requests against production; do not use real
payment credentials or card data.

Checklist:
- user ledger owner scope and admin access
- atomic credit spend, idempotency, insufficient-credit rejection
- non-admin settings/provider/credit writes return 403
- provider default is server-side and token-capable only
- BIN endpoint accepts exact six-digit BIN metadata only
- provider action redirects are HTTPS and never persist client secrets/raw body
- capture modes never exceed the authorization or auto-fallback to a sale
- UI has no provider selector for non-admin users
- admin grants and settings writes create audit records

Report PASS/FAIL with concrete command output. Any provider sandbox or database
check that cannot run without external credentials must be marked NOT RUN, not
PASS. Finish only when the safe checks pass and list remaining limitations.

# S5 — Explicit capture workflow

Reuse the owner-scoped POS transaction flow in `PaymentService`. Support
`FULL_AUTH`, `BELOW_AUTH`, and `CUSTOM` capture amounts; calculate `PCT_120`
for display but reject it when it exceeds the approved authorization. Never
automatically fall back to a sale or capture above the provider authorization.
Any separate sale must be a distinct user-confirmed POS operation using an
existing provider token. Preserve idempotency, audit records, and reconciliation
state when a provider response is uncertain. Include safe examples.
